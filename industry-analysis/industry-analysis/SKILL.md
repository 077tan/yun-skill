# 二级市场行业分析（Industry Analysis · Buy-Side）

> 一句话定位：站在基金经理 / 买方研究员视角，把任意行业拆成可投资、可跟踪、可决策的结构化认知框架。

## 适用场景

1. **建仓前研究** —— 首次覆盖新行业，需要构建完整投资框架
2. **会议前预习** —— 路演 / 公司调研 / 内部晨会前的快速 brief
3. **存量持仓复盘** —— 已持仓行业的景气度、竞争格局、预期差变化
4. **主题轮动判断** —— 判断行业当前所处周期阶段、是否到了买点/卖点
5. **跨行业对比** —— 用统一框架横向对比多个行业的吸引力

## 输入

- **行业名称**（必填）：如 "PCIe Switch"、"创新药CXO"、"光伏硅料"、"工业母机"
- **分析深度**（可选）：`quick` 一页纸（30分钟）/ `standard` 标准深度（1-2小时）/ `deep` 深度报告（含 Word + Excel）
- **分析视角**（可选）：`investment` 投资视角（默认）/ `industry` 产业视角

## 输出模块（17 大模块 · 比标准版扩展 8 个）

### 一、行业认知层（建立基本面框架）

**1. 行业定义与边界**
- 行业范畴、细分赛道划分（按技术路线 / 应用场景 / 客户类型）
- 与相邻行业的边界、易混淆概念辨析

**2. 行业周期定位** ⭐ 新增
- 当前处于「导入期 / 成长期 / 成熟期 / 衰退期 / 复苏期」哪个阶段
- 库存周期位置（主动补库 / 被动补库 / 主动去库 / 被动去库）
- 给出周期判断的 3 条核心证据

**3. 产业链全景**
- 上中下游结构图（文字版可用 ASCII 或 Mermaid）
- 各环节价值量分布、利润率分布
- **量价传导路径** ⭐ 新增：上游涨价→中游谁能转嫁/谁被挤压→下游需求弹性

**4. 市场规模与空间**
- 全球 / 中国市场规模（金额 + 单位数量）、历史增速、未来 3-5 年 CAGR
- 渗透率曲线（当前位置 vs 天花板）
- 关键假设：测算逻辑透明化（防 PPT 工程）

### 二、竞争格局层（找出 alpha 来源）

**5. 竞争格局**
- CR3 / CR5 / HHI 集中度
- 主要玩家市场份额、定位（高端/中端/低端、特种/通用）
- 进入者 vs 在位者动态

**6. 海外对标映射** ⭐ 新增
- 海外可比公司（如 PCIe Switch 对标 Broadcom/Microchip/Astera Labs）
- 海外标的估值锚 → 映射到 A 股 / 港股估值
- 海外股价驱动因素能否复制到国内

**7. 核心壁垒**
- 技术壁垒（专利 / 工艺 know-how / 研发投入）
- 规模壁垒（产能 / 成本曲线）
- 资质 & 客户壁垒（认证周期 / 供应链绑定）
- 网络效应 / 转换成本
- **壁垒可持续性评分**（1-5 分，给出理由）

### 三、驱动与估值层（找出 beta 来源）

**8. 驱动因素**
- 需求侧：政策 / 应用 / 替代
- 供给侧：产能投放节奏 / 技术变革 / 集中度变化
- 三大边际变化（最近 6 个月发生了什么新事）

**9. 估值体系适配** ⭐ 新增
- 该行业适用哪种估值法：PE / PB / PS / PEG / EV/EBITDA / DCF
  - 周期股 → PB + ROE
  - 成长股 → PE + 增速 / PEG
  - 重资产 → EV/EBITDA
  - 早期 → PS / 渗透率折现
- 历史估值分位（过去 5/10 年的中位数、+1σ、-1σ）
- 当前位置在分位区间的哪里

### 四、个股层（落到可投资标的）

**10. 主要上市公司**
- A 股 / 港股 / 美股代表性标的清单（含代码、市值、最新 PE/PB）
- 每家公司的「一句话定位」+ 「核心看点」+ 「核心风险」
- 表格化输出

**11. 龙头 alpha vs 行业 beta 拆分** ⭐ 新增
- 行业 beta 来自什么（景气度 / 政策 / 渗透率）
- 龙头 alpha 来自什么（份额提升 / 产品升级 / 出海）
- 当下买行业 ETF 划算还是买龙头划算

**12. 一致预期 vs 预期差** ⭐ 新增
- Wind / 卖方一致预期增速
- 我方判断 vs 一致预期的偏差点
- 预期差催化路径（什么事件会让市场修正预期）

### 五、跟踪与风控层（投后管理）

**13. 资金流与机构持仓** ⭐ 新增
- 北向资金过去 N 月行业流入 / 流出
- 公募基金行业仓位变化（超配 / 低配）
- 龙虎榜 / 大宗交易异动

**14. 催化剂日历** ⭐ 新增
- 未来 6 个月可能催化股价的事件清单（业绩披露 / 政策窗口 / 产能投放 / 大客户订单 / 海外对标财报）
- 按时间排序、标注重要程度

**15. 关键指标 / 高频跟踪**
- 行业景气度领先 / 同步 / 滞后指标
- 数据获取频率（日 / 周 / 月）和来源
- 给出可直接接入的 akshare 接口名（如 `stock_board_industry_hist_em`）

**16. 投资风险**
- 系统性风险（政策 / 周期 / 汇率）
- 行业特定风险（技术路线被颠覆 / 客户集中 / 应收账款）
- ESG & 监管风险

**17. 反向信号 / 雷区扫描** ⭐ 新增
- 大股东减持节奏
- 商誉占净资产比例（>30% 标红）
- 应收账款 / 营收占比异动
- 存货周转放缓
- 审计意见 / 关键人变动

## 数据来源（4 个核心抓手）

| 数据源 | 类型 | 覆盖能力 | 适用模块 |
|---|---|---|---|
| **akshare** | Skill 调用 | A股/港股板块行情、资金流、北向、龙虎榜、研报摘要、宏观经济、行业 PE/PB 历史分位、公募仓位、商品期货 | 模块 3/4/5/9/10/13/15/17 |
| **yfinance** | Skill 调用 | 海外对标公司实时行情、历史K线、财报、期权链、持仓 | 模块 6/9/10 |
| **WebSearch** | 工具调用 | 最新产业新闻、政策催化、海外动态、卖方研报观点、产业事件日历 | 模块 2/7/8/12/14/16 |
| **polymarket** | Skill 调用 | 海外预测市场赔率（政策/选举/地缘催化对行业的影响） | 模块 8/14（特定主题） |

> **底层逻辑**：4 个抓手覆盖 A 股 + 海外 + 新闻 + 预测市场四象限，闭环完整。不再依赖第三方研报平台（alphapai/company-research），所有数据可独立采集、可验证、可追溯。

## 执行流程

```
Step 1 │ 输入解析与行业边界确认（必要时反问用户）
Step 2 │ 数据采集（并行调用 akshare + yfinance + WebSearch + polymarket）
Step 3 │ 模块分层填充（17 模块逐个落表）
Step 4 │ 自检：每个数字必有来源、每个观点必有证据
Step 5 │ 输出（Markdown 主稿 → 可选 Word → 可选 Excel 估值表）
Step 6 │ 投资结论：给出 1-3 条可执行 take-away
```

## 输出格式要求

- **数字密度**：每 100 字必须含至少 1 个具体数字（市场规模 / 增速 / 份额 / 估值分位）
- **来源透明**：所有数字标注来源 + 时间戳
- **避免 PPT 化**：不要 "巨大空间 / 广阔前景" 这种空话，要 "全球市场 23 亿美元，CAGR 28%，2027 年到 50 亿美元"
- **二级市场视角**：每个判断要能回答 "这个事让股价怎么动"
- **买方口吻**：口语化专业表达，可用 e / X / kw / pct 等买方简写

## 反模式（禁止做的事）

1. ❌ 抄卖方研报结论而不质疑
2. ❌ 给出"千亿市场"等无来源数字
3. ❌ 把 17 个模块写成 17 段废话堆叠 —— 没有数据支撑的模块直接标 "数据待补"
4. ❌ 只看国内不看海外对标
5. ❌ 只看龙头不看产业链上下游传导
