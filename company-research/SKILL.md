# 公司研究——深度研究报告技能

## 概述

本技能帮助基金经理对上市公司进行系统性研究，生成机构级深度研究报告（Word .docx格式）。
报告综合用户提供的材料与Claude自行搜集的公开信息，按照五部分框架结构输出。

---

## 用户会提供的材料

- 招股说明书（PDF）
- 历年年度报告 PDF（重点：利润表、资产负债表、现金流量表）
- 季度/半年度报告 PDF
- Excel 财务报表（三张报表：利润表、资产负债表、现金流量表）
- 日度前复权收盘价时间序列（Excel）
- 调研访谈纪要（Word）

**财务报表处理原则：**
用户不会预先整理好财务数据，Claude需自行合并科目，参考规则如下：
- 经营性应收 = 应收票据 + 应收账款 + 其他应收款 + 应收款项融资 + 合同资产
- 短期负债 = 短期借款 + 应付票据 + 一年内到期的非流动负债
- 经营性应付 = 应付账款 + 应付职工薪酬 + 应交税费
- 现金+固收+理财 = 货币资金 + 交易性金融资产 + 其他流动资产（含理财部分）
- 其他科目按占比重要性判断是否单独列示，占比小的合并为"其他"

## 第一步：信息收集

在开始撰写报告前，逐一读取用户上传的所有文件，同时通过网络搜索补充以下信息：

1. `[公司名] 公司简介 主营业务 成立时间 上市时间`
2. `[公司名] 实际控制人 股东结构`
3. `[公司名] 行业地位 竞争格局`
4. `[公司名] 最新公告 近期动态`
5. `[公司名] 指数成分股`（判断属于哪些重要指数）
6. A股用上证指数、港股用恒生指数、美股用标普500，搜索对应指数历年涨跌幅用于相对收益计算
7. **【判断上市路径】**：搜索 `[公司名] 借壳 重组上市 IPO 分拆上市`，确定属于哪种类型（A/B/C/D/E），并据此确定逐年阅读起始年——**此步骤必须在撰写第二部分之前完成**

## 第二步：报告结构（五部分框架）

报告分为五个部分，**必须按顺序全部完成**。

---

### 封面

- 公司名称（中英文）+ 股票代码 + 交易所
- 报告日期
- 一句话核心观点（≤60字，直接说明公司现阶段最重要的投资判断）
- 免责声明：仅供内部参考，不构成投资建议

---

### 第一部分：公司基本情况

#### 1.1 企业基本信息

用信息表（两列：项目 / 内容）列示以下内容：
- 成立时间
- A股/港股/美股上市时间及地点（若为借壳上市，注明借壳时间）
- 股票代码
- 注册地
- 企业性质（国企/民营/外资）
- 实际控制人姓名及背景简介（2-3句话）
- 主要生产基地或业务基地
- 近期重大资本运作（如有：定增、回购、并购等）

所属重要股票指数表：
| 指数名称 | 备注 |
|---------|------|

#### 1.2 股价表现总览

年度股价表现对比表，列示以下五列（**不要列"区间前复权价格区间"列**）：

| 年度 | [公司名]年度涨跌幅 | [基准指数]年度涨跌幅 | 相对收益 | 主要驱动 |
|-----|-----------------|------------------|---------|---------|

- A股对比上证综合指数，港股对比恒生指数，美股对比标普500
- 若为当年上市，自上市首日起计算，注明*号
- 主要驱动一栏用15字以内概括该年核心逻辑

#### 1.3 财务概况（压缩报表）

覆盖所有可获得年份，数据来自用户上传的Excel和PDF，单位统一为亿元。

**利润表摘要**，包含以下科目：
- 收入（亿元）
- 收入同比增速
- 毛利（亿元）
- 毛利率
- 四费费用率（销售+管理+财务+研发合计/收入）
- 营业利润（亿元）
- 营业利润率
- 归母净利润（亿元）
- 归母净利润增速
- 归母净利率

**资产负债表摘要**，包含以下科目（按上述合并规则处理）：
- 现金+固收+理财
- 经营性应收
- 存货
- 固定资产
- 在建工程
- 无形资产
- 商誉+权益性投资
- 其他高占比科目（单独列示）
- 资产总计
- 短期负债（短借+到期非流）
- 长期借款+应付债券
- 预收+合同负债
- 经营性应付
- 其他负债
- 归母所有者权益

#### 1.4 社会舆论评价

用3-4段话描述：
- 公司在行业中的地位和历史口碑
- 在资本市场的形象演变
- 客户/合作伙伴对公司的评价
- 对整个行业/资本市场的意义

### 第二部分：年报逐年阅读与总结

> **信息来源说明**：本部分撰写时，应综合运用以下三类信息来源：
> 1. 用户上传的年报、财务报表等文件
> 2. 用户提供的调研访谈纪要、会议纪要（如有）——可直接引用管理层观点和表述
> 3. 网络公开信息（行业报道、新闻、卖方研报摘要等）——补充外部视角和行业背景

#### 2.1 逐年经营情况（每年1000-3000字）

##### 【起始年份判定规则】——必须在撰写前先确定

逐年阅读的起始年份，不是简单地"拿到最早的数据就从那年开始"，而是找到**公司当前业务形态的历史起点**。按以下优先级判断：

**A. 借壳上市（重组上市）**
- 起始年 = 借壳完成当年（即新业务注入、证券代码变更的年份）
- 壳公司的历史年报**不读**，因为代表完全不同的业务实体
- 第一年写法：必须用专门段落交代借壳背景（原壳公司是谁、注入了什么资产、为何选择借壳而非IPO、重组完成后资本结构如何），然后才进入正常经营分析
- 同比增速数据：第一年无可比基础，同比栏标"——（首年合并报表）"
- 例：天山铝业2020年借壳新界泵业完成，故逐年阅读从2020年开始

**B. 标准IPO上市**
- 起始年 = IPO当年（不必回溯私有化阶段）
- 例外：若IPO在Q4且当年年报内容极少（仅含上市后数月），可简化处理或与次年合并描述，但不能省略
- 第一年写法：注明上市时间、募集金额及用途，以及上市对公司战略/融资能力的实质影响
- 同比增速数据：若用户提供了上市前一年（T-1年）的招股说明书财务数据，可计算同比；否则标"——"

**C. 长期上市公司（已上市10年以上）**
- 不要强行从上市第一年开始——年报太多会导致报告失焦
- 起始年判定优先级：
  1. 用户提供了哪些年报/财务数据 → 以用户实际提供的最早年份为起点
  2. 若用户未明确，寻找**公司历史上最近一次重大战略转型/资产重组/主业变更**的年份作为起点
  3. 若无明显转折点，默认取最近**7年**（确保覆盖至少一个完整行业周期）
- 起始年之前的历史：在封面"核心观点"或第一部分"社会舆论评价"中用1-2段话交代沿革，不单独展开逐年阅读

**D. 分拆上市 / 从母公司剥离**
- 起始年 = 分拆上市当年
- 必须交代：从母公司剥离的原因、独立上市后业务边界的变化、与母公司的持续关联交易

**E. 美股中概股（ADR / 纽交所 / 纳斯达克）**
- 按B或C规则处理，取决于上市年限
- 额外注意：若公司经历过私有化退市再重新上市（如360、完美世界），起始年 = **再上市年份**

---

##### 起始年特殊写法要求

无论上述哪种情形，**逐年阅读的第一年**都必须额外包含：

1. **公司身份确立段**（50-100字）：一句话说明公司以何种形式进入资本市场，以及这对后续历史叙述意味着什么
2. **财务数据注释**：第一年的同比数据如实标注为"——"或"首年，无可比基础"，不得捏造或用招股书口径强行填数（除非用户明确提供）
3. **前置历史补充**（如有实质意义）：若借壳前/上市前的公司有重要历史（如创业历程、技术积累），在第一年段落开头用斜体或括号简要交代，不超过200字

---

按时间顺序，从上述确定的最早年份到最新年份，逐年撰写，每年包含：

**核心财务数据**（必须列出具体数字）：
- 收入及同比增速
- 归母净利润及同比增速
- 扣非净利润及同比增速
- 毛利率及同比变化（以百分点表示）

**主要经营内容**（来自年报MD&A，重点提炼）：
- 外部宏观/行业环境
- 本年核心工作和经营亮点
- 产销情况、市场份额变化
- 主要客户/重要订单
- 研发进展
- 资本开支和投融资情况

**重大事项**（如有）：
- 重组、并购、剥离
- 股东结构变化
- 股权激励
- 重大政策影响

**管理层展望**（如有）：
- 对下一年的预期和规划

#### 2.2 综合总结

在逐年阅读之后，撰写综合总结，包含：

**业务发展脉络与商业模式**
- 公司的生意是怎么做的（上下游关系、收入来源、成本结构）
- 商业模式的核心竞争力在哪里

**行业周期分析**
- 识别公司历史上的景气高峰和低谷年份
- 每次周期好/坏时管理层给出的原因
- 周期规律总结

**关键战略决策复盘**
- 列出公司历史上2-4个重要的战略决策
- 每个决策的背景、当时逻辑、事后评价（正确/错误/时机不对）

### 第三部分：股价复盘

> **信息来源说明**：本部分应综合运用以下信息来源：
> 1. 用户提供的日度前复权收盘价数据（主线）
> 2. 网络公开信息（公告、政策文件、行业新闻、重大事件报道）——用于标注股价拐点对应的催化事件
> 3. 用户提供的会议纪要（如有）——可引用管理层对特定时期经营状况的描述，与股价走势相互印证

基于用户提供的日度前复权收盘价数据，识别主要上涨和下跌周期。

每个周期包含：
- 时间范围（起止日期）+ 幅度（最大涨跌幅）
- 对应的事件（公告、政策、行业消息）
- 对触发信号和见顶/见底信号的分析（**明确标注为推断**）

写作风格：
- 用叙事风格，不只是事件列表
- 将股价走势与基本面变化相结合
- 对市场情绪和预期的变化要有描述

---

### 第四部分：思考第一阶段——定性认识

> **信息来源说明**：本部分的判断应建立在前三部分分析基础上，同时可参考：
> 1. 用户提供的会议纪要（如有）——管理层对公司战略、竞争力的自我描述
> 2. 网络公开信息（行业分析文章、竞争对手动态、客户评价等）——提供外部独立视角

用平实直接的语言，500-1000字，回答以下问题：
- 这是一家好公司还是差公司？为什么？
- 这是值得长期跟踪基本面的标的，还是主题/流动性交易品种？
- 公司的历史折射了哪些宏观/行业趋势？
- 管理层的战略能力和执行力如何评价？
- 公司最核心的矛盾或风险是什么？

风格要求：直接说结论，不要模棱两可，不要回避判断。

---

### 第五部分：思考第二阶段——当下定价与交易逻辑

> **信息来源说明**：本部分应重点结合最新信息，综合运用：
> 1. 网络公开信息（最新财报、卖方一致预期、近期新闻、机构观点）——判断当前市场叙事和定价
> 2. 用户提供的最新会议纪要（如有）——了解管理层对当前经营和展望的最新表述，与市场预期对比

用平实直接的语言，500-1000字，回答以下问题：
- 当前市场在讲什么故事？主流叙事是什么？
- 当前定价隐含的盈利预期是多少？（倒推）
- 市场上的主要分歧在哪里？多空双方各自的逻辑是什么？
- 上行催化剂有哪些？（列举2-4个）
- 下行风险有哪些？（列举2-4个）
- 横向比较：同一主题下有没有更好的替代标的？（做不充分也可以，不是主要需求）
- 买/卖/持有建议：直接给出结论，说明介入价位或离场条件

风格要求：直接说结论，如果公司没有投资价值就直说，不要因为礼貌而回避判断。

## 第三步：生成 Word 文档

**直接调用打包脚本，无需手写 docx.js 代码。**

格式已固化在 `scripts/generate_report.py`（python-docx 实现）。JSON 数据结构见 `references/report_schema.md`。

### 执行步骤

```bash
# 1. 安装依赖（沙箱环境每次需要）
pip install python-docx --break-system-packages -q

# 2. 将报告内容整理为 JSON，存为 /home/claude/report_data.json
#    字段结构参见 references/report_schema.md

# 3. 运行生成脚本
python scripts/generate_report.py \
  --data /home/claude/report_data.json \
  --output /home/claude/[公司名]_深度研究报告_[日期].docx

# 4. 验证文件
python /mnt/skills/public/docx/scripts/office/validate.py \
  /home/claude/[公司名]_深度研究报告_[日期].docx

# 5. 复制到输出目录
cp /home/claude/[公司名]_深度研究报告_[日期].docx /mnt/user-data/outputs/
```

### JSON 整理原则

- 所有数值字段均为字符串（已含格式，如 `"19.1"` `"+100.5%"`），脚本不做计算
- 缺失字段直接省略，脚本自动跳过对应段落/表格，不报错
- 较长段落直接换行为列表中多个字符串，每个字符串对应一个自然段
- 完整字段说明见 `references/report_schema.md`

---

> **仅在脚本无法处理的特殊格式需求时**，才回退到读取 `/mnt/skills/public/docx/SKILL.md` 手写代码。

## Word 报告格式规范（实测自天山铝业成品报告，严格执行）

> **本节是格式的唯一权威来源，脚本已内置所有参数，禁止手动覆盖。**

### 页面设置

| 参数 | 值 |
|------|-----|
| 纸张 | US Letter（8.5" × 11"） |
| 左右边距 | 2.22 cm（1260 DXA） |
| 上下边距 | 2.54 cm（1440 DXA） |
| 版心宽度 | 9720 DXA（6.75 inch） |

### 字体

- **全文统一使用 Arial**（中文字符通过 `w:eastAsia="Arial"` 强制为 Arial，不使用宋体/黑体）
- python-docx 中必须同时设置 `run.font.name = "Arial"` 和 `run._r.rPr.rFonts.set(qn('w:eastAsia'), "Arial")`

| 表格数据文字 | 10pt | - | 黑色 | 左列左对齐，其余居中 |
| 页眉页脚 | 9pt | - | DARK_BLUE/GRAY | 见下方 |

### 段落间距（DXA，1440=1inch=72pt，即20 DXA≈1pt）

| 元素 | 段前 | 段后 |
|------|------|------|
| H1 | 360 (18pt) | 120 (6pt) |
| H2 | 240 (12pt) | 80 (4pt) |
| `add_label` | 180 (9pt) | 60 (3pt) |
| `add_body` | 60 (3pt) | 60 (3pt) |
| `add_note` | 40 (2pt) | 40 (2pt) |

### 专用排版函数对照

| 函数 | 用途 | 示例触发场景 |
|------|------|-------------|
| `add_h1(doc, text)` | 一级标题 + 底部蓝线 | "第一部分：…" |
| `add_h2(doc, text)` | 二级标题 | "1.1 企业基本信息" |
| `add_body(doc, text)` | 正文段落 | 任何叙述性文字 |
| `add_label(doc, text)` | 小节内粗体标签 | "利润表摘要（单位：亿元）"、年份标题"2020" |
| `add_note(doc, text)` | 灰色小字注释 | "注：以上数据来源于…" |
| `add_bullet(doc, text)` | 项目符号列表 | 催化剂、风险事项 |
| `make_info_table(doc, rows_data)` | 双列信息表（项目\|内容） | 企业基本信息、股票指数 |
| `make_data_table(doc, headers, rows, col_widths)` | 多列数据表 | 财务数据、股价表现 |

### 表格规范

- **表头行**：DARK_BLUE 背景 + 白色 10pt 粗体 + 居中
- **数据行**：FFFFFF（奇数行） / F2F2F2（偶数行）交替，10pt 黑色
- **单元格边框**：4 sides single，auto color
- **单元格内边距**：top/bottom=80 DXA，left/right=120 DXA
- **表格总宽**：9720 DXA（充满版心），`set_table_width()` 强制设置

### 页眉页脚

**页眉**（含底部蓝线）：
```
[公司名]（[股票代码]）   深度研究报告   [报告日期]
─────────────────── 蓝色细线 (#2E75B6, sz=6) ───────────────
```
- 公司名部分：9pt, DARK_BLUE
- "深度研究报告 + 日期"部分：9pt, GRAY

**页脚**（居中）：
```
第 [页码] 页  |  本报告仅供内部参考，不构成任何投资建议
```
- 全部：9pt, GRAY
- 页码为自动域字段（PAGE field）

## 第四步：完整执行流程

1. 读取用户上传的**所有**文件（PDF、Excel、Word）

## 注意事项

- 年报逐年阅读是**核心章节**，必须做到逐年覆盖+详细归因，不能只列数字没有分析
- 第四、五部分要有明确判断，不能模棱两可
- 股价复盘中对原因的判断必须标注"推断"字样
- 如果用户没有提供某类材料（如股价数据），对应章节可简化处理，不必虚构
- 横向比较（第五部分）做不充分也可以接受，不是主要需求
- 报告目标长度：20-35页
